排版主题

为什么 Markdown 粘贴到公众号就没排版？

在 Markdown 编辑器里写好的文章，直接粘贴进微信公众号编辑器，常常变成一坨没有排版的纯文本：标题变成普通文字、代码块丢失配色、引用和列表全部拍平。原因是公众号、知乎等富文本编辑器在粘贴时会过滤 <style> 标签和 class 类名，只保留写在标签 style 属性里的行内样式。

MD2Post 在你点击「复制富文本」的那一刻，用 juice 把主题 CSS 自动内联进每一个标签的 style 属性，再连同纯文本一起写入系统剪贴板——排版原样落进编辑器，无需再手动调整。

三步上手

  1. 左侧粘贴或输入 Markdown，右侧实时预览；也可以把 .md 文件直接拖进页面；
  2. 挑选一套排版主题：极简黑白、微信绿、技术博客蓝、小红书卡片；
  3. 点右上角「复制富文本」（快捷键 Ctrl/Cmd + Enter），到公众号 / 知乎 / 掘金 / 飞书直接 Ctrl+V。

常见问题

MD2Post 是免费工具吗？

是。MD2Post 完全免费、无需注册登录，所有解析与排版都在你的浏览器本地完成，内容不会上传到任何服务器。

为什么 Markdown 粘贴到微信公众号排版会乱？

微信公众号、知乎等富文本编辑器在粘贴时会过滤 style 标签和 class 类名，只保留写在标签 style 属性里的行内样式。MD2Post 会用 juice 把主题 CSS 自动内联到每个标签上，因此粘贴后排版不丢。

MD2Post 支持粘贴到哪些平台？

支持微信公众号、知乎、掘金、飞书等保留行内样式的富文本编辑器；复制时同时写入富文本与纯文本两种格式，粘贴时自动按目标平台选择。

代码块高亮在公众号里能保留吗？

能。MD2Post 基于 highlight.js 高亮，并在复制时把每个代码 token 的颜色直接写进行内样式，粘贴后依然保留深色代码块与配色。

我写的文章会被上传或保存到云端吗？

不会。MD2Post 无后端服务器，草稿仅保存在你自己浏览器的 localStorage 里，清除浏览器数据前会一直保留。

粘贴到公众号提示“检测到 Markdown 写法”怎么办？

这是公众号自带的 Markdown 辅助转换提示，不影响已粘贴的富文本样式：点提示条上的 × 忽略即可，切勿点击“转换”——它会按纯 Markdown 重新渲染，丢失内联排版。触发原因通常是正文包含代码块、反引号、星号等类 Markdown 字符。

为什么粘贴到 X（Twitter）文章编辑器会丢样式？

直接粘贴带行内样式的富文本，X 解析不稳定（丢标题、段落合并）。解决方法：勾选预览栏的「X 兼容」后点复制，MD2Post 会输出纯净语义 HTML——保留 H2/H3 标题、加粗、斜体、列表、引用、链接、代码块，表格自动转文本行——然后直接粘贴到 X 文章编辑器正文。颜色、字号、背景等视觉样式 X 一律剥离，属平台限制。
